# Proyecto--Sistema-Backend-de-flota-y-alquiler-de-vehiculos-EcoDrive
README.md — EcoDrive

Descripción
EcoDrive es un proyecto web centrado en la movilidad sostenible.

La aplicación tiene como objetivo ofrecer una solución digital que facilite a los usuarios el acceso a servicios y funcionalidades relacionadas con una movilidad más responsable, proporcionando una interfaz sencilla, intuitiva y accesible.


 Objetivos
Los principales objetivos de EcoDrive son:


 Facilitar el acceso a servicios relacionados con la movilidad.

 Desarrollar una aplicación web funcional e intuitiva.

 Aplicar buenas prácticas de desarrollo web.

 Crear una base que permita ampliar las funcionalidades de la aplicación.
